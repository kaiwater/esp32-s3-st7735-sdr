# v0.2.1 — 2026-10-31

修复宽 span 下频谱/瀑布中央出现大凹陷的问题。

## 原因

`spectrum_snapshot()` 返回的是**自然 FFT 顺序**：

- bin 0 = DC
- bin n/2 = Nyquist
- 后半段是负频率

`st7735_draw_bins()` 直接按 `bins[j]` 映射到屏幕列，所以屏幕中间显示的
其实是 Nyquist，而不是调谐中心。span 越大，Nyquist 附近的凹陷越明显，
80 MHz 时看起来像“中间没有数据”。

## 修复

显示前把 bins 旋转 `n/2`：

```c
unsigned code = bins[(j + n / 2) % n];
```

这样 DC 落在屏幕中心，左右分别是 −span/2 和 +span/2，和频率刻度一致。
参考实现：S2 Feather 的 `feather_tft.c` 也是这么做的。

## 验证

- 16 / 40 / 80 MHz 三个 span 中央不再有 Nyquist 凹陷
- 调谐中心信号显示在屏幕中央
- 瀑布同步修正
