# v0.2.1 — 2026-10-31

修复宽 span 下的频谱中心异常，并新增长按操作。

## 原因

`spectrum_snapshot()` 返回的是**自然 FFT 顺序**：

- bin 0 = DC
- bin n/2 = Nyquist
- 后半段是负频率

`st7735_draw_bins()` 直接按 `bins[j]` 映射到屏幕列，所以屏幕中间显示的
其实是 Nyquist，而不是调谐中心。span 越大，Nyquist 附近的凹陷越明显，
80 MHz 时看起来像“中间没有数据”。

## 修复

显示前把 bins 旋转 `n/2`：

```c
unsigned code = bins[(j + n / 2) % n];
```

这样 DC 落在屏幕中心，左右分别是 −span/2 和 +span/2，和频率刻度一致。
参考实现：S2 Feather 的 `feather_tft.c` 也是这么做的。

## 追加修复：DC/LO 泄漏

移位后中心变成 DC，宽 span 下出现明显的中央凸起。原因是 IQ 里存在
DC/LO 偏置，Hann 窗把偏置泄漏到 bin 0~4。现在在 `spectrum_snapshot()`
里先算 I/Q 均值并在**时域**减掉，再窗口化 FFT，中心恢复平坦。

## 新增长按操作

- 长按 K1/K2：加速调谐，步进 5 → 10 → 25 → 50 → 100 MHz
- 长按 K3：2500 MHz（最高）↔ 1850 MHz（最低）
- 长按 K4：回到 2412 MHz 并恢复刷新
- 长按阈值 700ms，K1/K2 重复间隔 120ms

## 验证

- 16 / 40 / 80 MHz 三个 span 中央不再有 Nyquist 凹陷
- 中央 DC 凸起明显减弱
- 调谐中心信号显示在屏幕中央
- 瀑布同步修正
