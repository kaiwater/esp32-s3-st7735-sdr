# v0.2.0 — 2026-10-31

阶段 2/3 完成：ESP-SDR S3 接入、实时频谱/瀑布、调谐 UI，全部实机验证。

## 新增

- `firmware/`：完整 ESP-SDR fork，内置 `esp-dsp` 和 `esp_lcd_st7735`
- `acquire_iq()`：只采集 raw I/Q，不向主机发送
- `spectrum_snapshot()`：256-bin 片内 FFT 快照
- `st7735.c/.h`：ST7735 驱动、条带渲染、UI、按键
- `lcd_task()`：K1/K2 调谐、K3 span、K4 暂停
- 大号频率读数 + 实心频谱 + magma 瀑布的新 UI
- `bringup/`：阶段 1 demo 移到独立子目录

## 修复 / 关键实现

- 解决链接错误 `S3 RF ring overlaps BSS`：
  - S3 上把 `ring_capture.c` 的 `txq`、`win2`、`fft_buf`、`bin_of` 改成堆分配
  - S3 `MAX_FFT` 降到 256
  - `_bss_end ≈ 0x3fca7380`，距 RF ring 约 36KB
- 解决 40KB 全屏帧缓冲分配失败：
  - WiFi/PHY 启动后 DMA 内部内存只剩约 24KB，最大块约 15KB
  - 改为 8 行条带缓冲（2.5KB），16 次刷屏，DMA 完成回调复用
- IDF 5.4.2 兼容：
  - `cpu_utility_ll_enable_clock_and_reset_app_cpu()` shim
- 修正 S3 采样率映射：80 / 40 / 16 MS/s（rate code 0 / 1 / 6）

## 实机验证

- 屏幕 160x128 无偏移/变形
- 频谱连续刷新（约 5fps），瀑布正常滚动
- K1/K2 以 5MHz 步进调谐
- K3 在 16 / 40 / 80 MHz 之间切换
- K4 暂停/恢复，暂停时显示 `PAUSED  K4 RESUME`
- 连续运行无重启/panic

## 已知限制

- S3 实际主要覆盖约 1.85–2.5GHz，UI 允许输入 100–6000MHz
- 快照之间有 gaps，显示相对强度，不是校准 dBm
- 无 PSRAM，瀑布 28 行
- 串口 `CAP`/`SPEC` 与屏幕刷新不要同时使用
- 电池、外壳、长期稳定性未验证
